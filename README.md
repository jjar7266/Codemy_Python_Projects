# 🚀 Codemy.com Python Projects Course – Learning Repository

This repository documents my progress through the **Python Projects Course**
from **Codemy.com**, taught by **John Elder**.

The focus of this course is building practical Python applications while
reinforcing programming concepts through real-world projects. Each project
provided an opportunity to apply Python fundamentals, problem-solving skills,
and project organization techniques learned throughout my programming journey.

This repository serves as both a personal learning archive and a collection
of completed Python projects created while working through the course.
